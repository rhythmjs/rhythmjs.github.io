Drizzle on Bun's native SQL

The database is a provider with a dispose hook, the queries live in a service factory, and Drizzle talks to PostgreSQL through Bun.SQL — no driver package.

Install #

Drizzle's drizzle-orm/bun-sql entry runs on Bun's built-in SQL class, so PostgreSQL needs no pg or postgres.js dependency — drizzle-kit is only a dev tool for generating and applying migrations. The wiring below follows the shared shape from the overview.

The database provider #

The factory returns the drizzle instance under db and the raw client under the hash-key "#client". Hash-prefixed keys never reach the request context or the provider graph, but the dispose hook receives the whole value — so the pool stays private and still gets closed when the module tears down.

Table and service #

Everything notes-related lives under src/notes/: the table, the zod schemas, the service, and the controller. Ids are plain text columns defaulted from crypto.randomUUID() in JavaScript, so a malformed id in the URL is an empty result instead of a database type error.

The service is a factory over the typed database. It owns every query; nothing else in the app touches drizzle. returning() turns updates and deletes into found-or-not answers without a second round trip.

Wiring the module #

The app module chains it together: a filter() error boundary first, then the database provider, then the service provider — which receives db from the provider graph — then the controller. Handlers throw HttpError for missing notes; validate("body", …) guards the writes and intercept(…) enforces the response contract.

On shutdown, appModule.teardown() disposes providers in reverse order: the service (nothing to do) and then the pool.

Migrations #

drizzle-kit generate diffs notes.table.ts against the last snapshot and emits a SQL migration into drizzle/ — no database needed. drizzle-kit migrate applies whatever is pending.

Where to next #

The same shape with a generated client: Prisma. A unit-of-work ORM that forks per request: MikroORM. No ORM at all: MongoDB. The full app is examples/drizzle-postgres.

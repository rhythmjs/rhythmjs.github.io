## Install

[Scalar](https://scalar.com) renders an OpenAPI document as an interactive API reference. `@rhythmjs/openapi` ships it as the default UI, so there is nothing extra to install.

```bash
bun add @rhythmjs/openapi @rhythmjs/rhythm @rhythmjs/router
```

## Serve the reference

`apiDocument` answers `GET /openapi.json` with the document generated from your router, and `apiReference` answers `GET /docs` with a Scalar page that loads that document. Mount both before the router so they get first look at the request.

```ts
import { Rhythm } from "@rhythmjs/rhythm";
import type { RhythmHttpContext } from "@rhythmjs/router/context";
import { defineDocument } from "@rhythmjs/openapi/document";
import { apiDocument, apiReference } from "@rhythmjs/openapi/docs";
import { users } from "./users";

const config = defineDocument({
  info: { title: "Users API", version: "1.0.0" },
  servers: [{ url: "https://api.example.com" }],
});

export const app = new Rhythm<RhythmHttpContext>()
  .use(apiDocument({ router: users, config }))
  .use(apiReference({ title: "Users API" }))
  .use(users.middleware());
// GET /openapi.json => the document, GET /docs => the Scalar page
```

## Change the paths and title

`apiReference` takes `path` (where the page is served), `specUrl` (where it reads the document from) and `title`. Point `specUrl` at an external document to document an API that another service owns. The value is HTML-escaped into the page.

```ts
apiReference({
  path: "/reference",
  specUrl: "/openapi.json",
  title: "Users API reference",
});
```

## Export the document

The document is a plain object, so you can write it to disk, for example to publish it or to feed a client generator. `generate` returns it directly, and `includeUndocumented: false` leaves out routes you have not described.

```ts
import { generate } from "@rhythmjs/openapi/generate";
import { config } from "./config";
import { users } from "./users";

const document = await generate(users, config, { includeUndocumented: false });
await Bun.write("openapi.json", JSON.stringify(document, null, 2));
```

## Things to check

- **The page loads Scalar from a CDN.** It is a static HTML shell that pulls the UI script from `cdn.jsdelivr.net`, so it needs network access in the browser, and a strict Content-Security-Policy must allow that host for the docs path.
- **The document is public by default.** Anyone who can reach `/openapi.json` can read your routes. If the API is private, serve the document and page from a path your network or proxy restricts.
- **Describe your routes.** Undocumented routes appear with a default `200` response; the [OpenAPI package](/openapi/) shows how to describe parameters, bodies and responses so the reference is useful.

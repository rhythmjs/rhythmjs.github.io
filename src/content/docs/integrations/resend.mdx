## Install

```bash
bun add resend
```

## A service wraps the client [#service]

The client holds only an API key, so there is nothing to close. A plain service creates it lazily and sends; the app module decorates its startup context with the service, and tests stub it. Until a domain is verified, send from Resend's `onboarding@resend.dev`, the default here.

```ts
// src/mail/mail.service.ts
import { Resend } from "resend";

const FROM = process.env.MAIL_FROM ?? "RhythmJS <onboarding@resend.dev>";

let client: Resend | undefined;

export const mailService = {
  send(to: string, subject: string, html: string) {
    client ??= new Resend(process.env.RESEND_API_KEY);
    return client.emails.send({ from: FROM, to, subject, html });
  },
};

export function escapeHtml(value: string): string {
  return value.replace(/[&<>"']/g, (char) => `&#${char.charCodeAt(0)};`);
}
```

## The controller checks the result [#controller]

`emails.send` does not throw for API errors. It resolves to `{ data, error }`, so the `POST /contact` route checks `error` and answers 502 instead of reporting success. User input is escaped before it goes into the HTML.

```ts
// src/app.controller.ts
import { RhythmRouter } from "@rhythmjs/router";
import type { RhythmHttpContext } from "@rhythmjs/router/context";
import type { appService } from "./app.service";
import { escapeHtml, type mailService } from "./mail/mail.service";

export type AppContext = RhythmHttpContext & {
  appService: typeof appService;
  mailService: typeof mailService;
};

export const appController = new RhythmRouter<AppContext>()
  .get("/", (ctx) => {
    ctx.text(ctx.appService.getHello());
  })
  .post("/contact", async (ctx) => {
    const { email, message } = (await ctx.request.json()) as { email?: string; message?: string };
    if (!email?.includes("@") || !message) {
      ctx.error(400, "a valid email and a message are required");
      return;
    }

    const { data, error } = await ctx.mailService.send(email, "We got your message", `<p>${escapeHtml(message)}</p>`);
    if (error) {
      ctx.error(502, "Could not send the email");
      return;
    }

    ctx.json({ id: data.id }, 202);
  });
```

## Put the service on the context [#module]

```ts
// src/app.module.ts
import { Rhythm, decorate, mount } from "@rhythmjs/rhythm";
import { appController } from "./app.controller";
import { appService } from "./app.service";
import { mailService } from "./mail/mail.service";

export const appModule = new Rhythm({ name: "app" })
  .register(decorate(() => ({ appService, mailService })))
  .use(mount(appController));
```

## Things to check

- Tests stub `mailService.send` (for example with `spyOn`), so nothing touches the network.
- `RESEND_API_KEY` is read when the first email is sent.

The full app, with tests, is [examples/resend](https://github.com/rhythmjs/examples/tree/main/examples/resend), built from the [template](https://github.com/rhythmjs/template).

API reference

Every export of @rhythmjs/ws: one class and the types around it.

class RhythmWs #

route(path, handlers)
Registers an endpoint. Data is this route's ws.data type; without an upgrade member it defaults to the route params. Throws TypeError for a non-object handlers argument.
guard(fn)
Adds an instance-wide guard, run in registration order before every matched route's upgrade. Guards never run for unmatched paths.
merge(child)
Copies the child's routes under this instance's prefix, snapshotting the child's guards at merge time and nesting them inside this instance's own. Later changes to the child do not propagate.
routes
The compiled route paths, prefix applied, in registration order.
upgrade(request, server)
The fetch-side half, bound as an arrow property. Returns null synchronously when the request has no upgrade: websocket header or matches no route; otherwise resolves to undefined once server.upgrade() succeeds, the rejecting Response from a guard or the route's upgrade, or 500 Upgrade failed when Bun refuses the socket.
websocket
The single behavior object for Bun.serve, spreading the constructor's WsBehavior tuning and dispatching every event to the connection's route via the ws.data identity. One behavior serves connections upgraded by any instance.

interface WsRoute<Data> #

Every lifecycle member is exactly Bun's WebSocketHandler member: ws is Bun's ServerWebSocket with send, subscribe, publish, cork, backpressure-aware return codes, and ws.data typed as Data. upgrade runs before server.upgrade(): return the connection's data, or a Response to reject the handshake. headers contributes to the 101 response, statically or computed per request.

type WsGuard #

A pre-upgrade check. Returning a Response rejects the handshake with it; any other return continues to the next guard, then the route's upgrade.

WsBehavior and RhythmWsOptions #

WsBehavior is Bun's websocket tuning, passed through to Bun.serve's behavior object verbatim by the websocket getter. prefix is prepended to every path this instance registers, and to merged children's paths.

Supporting types #

WsParams
Route params captured by rou3 for the matched path, the default ws.data when a route has no upgrade.
Server
Bun's server, as passed to fetch(request, server). Guards and route upgrades receive it for server.requestIP(), server.publish(), and similar.

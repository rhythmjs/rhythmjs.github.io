CLI API reference

Command routing, argv parsing, prompts, and response types for @rhythmjs/cli.

RhythmCli #

new RhythmCli({ name?, prefix? })
Create a command controller with an optional space-separated prefix.
command(path, ...handlers)
Add a command pattern with optional named tokens in ctx.args.
commands()
Return mountable command middleware.
use(fn) / provide(factory, dispose?)
Compose middleware, nested commands, and providers. register() throws.

RhythmCliContext and RhythmCliResponse are exported from @rhythmjs/cli/adapters/context. parseArgv and ParsedArgv are available from @rhythmjs/cli/argv.

Handlers, parsing, and prompts #

toCliHandler(app)
Each runtime adapter returns an (argv: string[]) => Promise<number> handler.
createPrompt()
Runtime adapters return { prompt, close } using readline-backed I/O.
createPrompt(io)
The lower-level @rhythmjs/cli/prompt export takes ask, write, and optional close functions.
parseArgv(argv)
The @rhythmjs/cli/argv export returns { positionals, flags }. Flag values are strings or booleans.
RhythmCliOptions / RhythmCliCommandContext
Root type exports describing constructor options and matched command arguments.
RhythmPrompt / RhythmPromptIO
Prompt method and I/O interfaces exported from @rhythmjs/cli/prompt.

See interactive prompts and CLI adapters for examples and cleanup.

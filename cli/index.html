CLI commands

Route arguments through the same middleware model.

Define a command #

Command patterns are space-separated tokens. Named tokens populate ctx.args. The first registered matching command wins, and its token count must match the positional arguments exactly.

Read flags and stdin #

ctx.flags holds string or boolean values. --verbose is true when no value follows; --target=prod supplies a string. A following non-flag token becomes a value, so --verbose deploy consumes deploy.

-abc is a single flag named abc, not three short flags. -- ends flag parsing. No schema validation or numeric coercion is performed.

ctx.stdin is a readable byte stream when input is piped, or null when stdin is a TTY.

Nest command groups #

Prefixes compose when you mount a child using commands(). Complete the child before mounting it.

Write output #

print(line), printError(line), and exit(code) are chainable. They buffer stdout, stderr, and the exit code. The adapter flushes stdout then stderr after the pipeline completes and returns the exit code (zero by default).

exit() sets a value; it does not terminate the process or stop middleware. Return without calling next() to stop downstream execution.

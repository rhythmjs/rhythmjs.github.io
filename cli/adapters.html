CLI runtime adapters

Run commands and interactive prompts on Bun, Node, and Deno.

Bun #

Import the Bun adapter for native Bun.stdin.stream() input. It exports toCliHandler and createPrompt.

Node #

The Node adapter uses Readable.toWeb(process.stdin) and readline-backed prompts. It has no Bun-specific API.

Deno #

The Deno adapter re-exports the Node implementation using Deno’s Node compatibility layer. Both the handler and prompt helper use the same API.

Execution and cleanup #

These snippets assume a configured cli. Each call receives argument tokens without the runtime and script path. The adapter creates the context, runs the pipeline, flushes stdout followed by stderr, and returns the numeric exit code.

Thrown errors reject the handler promise; the CLI adapter does not convert them into an exit code. Use try/finally to call cli.teardown(), especially when providers own readline prompts. Flat-mounted resource-owning children need their own teardown.

The packages currently export TypeScript source from private workspaces. Configure package resolution and TypeScript execution for your runtime.

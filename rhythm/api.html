Core API reference

The public API and types exported by @rhythmjs/rhythm.

Rhythm #

new Rhythm<TInput>(options?)
Create a pipeline. Options include name and type.
use<TExtra>(middleware)
Append a middleware step. Returns the same instance with an extended context type.
provide(factory, dispose?)
Add a sync or async object factory and optional cleanup callback. Resolved once, injected at its chain position so only later steps see it. Excludes # keys from context fields.
register(child, exportValue?)
Register a child Rhythm module, its lifecycle, and optional context exports. Accepts Rhythm instances only; controllers mount via use() instead.
run(input): Promise<TContext>
Initialize and dispatch one input, returning the final context.
callback(): (input) => Promise<TContext>
Get a cached reusable handler for the current middleware stack.
middleware(): Middleware<TContext>
Get flat middleware that shares its caller’s context and supports fallthrough.
setup(): Promise<void>
Resolve providers in order. Shares the initialization promise and permits retry after failure.
teardown(): Promise<void>
Await registered disposers in reverse order. Does not reset the instance.

Core exports #

compose(middleware[])
Return a dispatcher accepting a context and optional final next handler.
Middleware<TContext>
A (ctx, next) function returning void or Promise<void>.
NextFn<TContext>
Continue with optional extra context fields; resolves to readonly context.
DeepReadonly<T>
Recursively readonly types, except callable and RhythmMutable-branded values.
OmitHashKeys<T>
Remove keys beginning with # from an object type.
RhythmMutable
A unique symbol used to opt objects out of DeepReadonly.
RhythmOptions
Optional name and type labels, plus additional unknown option fields.

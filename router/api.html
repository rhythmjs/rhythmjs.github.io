Router API reference

Route methods, response types, and adapter exports for @rhythmjs/router.

RhythmRouter #

new RhythmRouter({ name?, prefix? })
Create an HTTP controller.
get / post / put / patch / delete(path, ...handlers)
Add handlers for a method and path. Matched parameters are in ctx.params.
routes()
Return mountable router middleware.
use(fn) / provide(factory, dispose?)
Compose middleware, nested routes, and providers. register() throws.

Context exports: RhythmHttpContext, RhythmResponse, RhythmResponseBody, and toResponse are available from @rhythmjs/router/adapters/context.

Adapter exports #

toFetchHandler(app)
Exported from adapters/bun and adapters/deno. Returns (request: Request) => Promise<Response>.
toNodeHandler(app, options?)
Exported from adapters/node. Returns an async IncomingMessage / ServerResponse handler.
RhythmNodeHandlerOptions
Node adapter options: bodyLimit?: number | false. Default: 1 MiB.
RhythmBodyTooLargeError
Exported Node adapter error class. The adapter converts this error into HTTP 413.
RhythmRouterOptions / RhythmRouterContext
Root type exports describing constructor options and matched path parameters.

See HTTP adapters for buffering, streaming, and error handling.

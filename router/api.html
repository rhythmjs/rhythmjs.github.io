Router API reference

Route methods, response types, and adapter exports for @rhythmjs/router.

RhythmRouter #

new RhythmRouter({ prefix? })
Create an HTTP controller. A router does not extend Rhythm; it compiles routes and middleware down to a single middleware.
get / post / put / patch / delete(path, ...handlers)
Add handlers for a method and path. Matched parameters are in ctx.params.
routes()
Return this router as a plain middleware, for mounting into a Rhythm app via use(). The only way a router reaches a runtime.
use(fn) / use(child)
Add a middleware, or mount a nested RhythmRouter with composed prefixes. Registration order is execution order: a middleware wraps only the routes registered after it. There is no provide() or register(); providers live on the host Rhythm app.
ctx.json(data, status?)
Serialize data as the body with an application/json content type; status is optional.
ctx.text(body, status?) / ctx.html(body, status?)
Set a plain-text or HTML body with the matching content type.
ctx.error(status, message?)
Set the status and a plain-text message, defaulting the message from the status code.
ctx.redirect(url, status?)
Set the location header with a 302 default and no body.

The helpers are sugar over ctx.response, built into the context by the adapters via createHttpContext. Context exports: RhythmHttpContext, RhythmResponse, RhythmResponseBody, createHttpContext, and toResponse are available from @rhythmjs/router/adapters/context.

Adapter exports #

toFetchHandler(app)
Exported from adapters/bun and adapters/deno. Takes a Rhythm app and returns (request: Request) => Promise<Response>.
toNodeHandler(app, options?)
Exported from adapters/node. Takes a Rhythm app and returns an async IncomingMessage / ServerResponse handler.
RhythmNodeHandlerOptions
Node adapter options: bodyLimit?: number | false. Default: 1 MiB.
RhythmBodyTooLargeError
Exported Node adapter error class. The adapter converts this error into HTTP 413.
RhythmRouterOptions / RhythmRouterContext
Root type exports describing constructor options and matched path parameters.

See HTTP adapters for buffering, streaming, and error handling.

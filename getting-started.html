Quick start

Go from the repository to your first running pipeline.

Set up the workspace #

Use Bun with this repository. The root manifest specifies bun@1.4.2. From the repository root, install its workspace dependencies:

Run an example #

The HTTP example serves on port 3000. Request /api/users/u1 to try its nested users router.

Try the CLI #

The CLI example includes remote commands and an interactive initialization flow. Remote data is in memory and does not persist between invocations.

Create a workspace app #

Add a directory under examples/ with this manifest, then run bun install at the root. Workspace dependencies resolve directly to the TypeScript source.

Write your pipeline #

Save this as index.ts in your new workspace and run it with bun run index.ts.

Check the repository #

Run the existing package tests and TypeScript checks from the root.

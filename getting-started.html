Quick start

Install the packages, write a pipeline, and serve your first routes.

Install the packages #

The kernel and the router are all you need to start. Every package is ESM and requires Node.js 20.19 or newer; Bun and Deno work through their own adapters.

Write a pipeline #

The kernel alone composes middleware over any input. Providers initialize once; middleware runs per input; the typed context carries both.

Serve HTTP #

The router registers routes with named parameters; the Node adapter turns the app into an ordinary request listener. Run it with npx tsx server.ts.

Add validation #

Ecosystem packages drop into the same chain. Here validate checks the body against a zod schema and exposes the typed output as ctx.valid.body; an invalid body answers 400 before the handler runs.

Where to go next #

Clone the starter template for a Nest-style skeleton with tests, read the philosophy, or browse the package groups in the sidebar: Middleware, HTTP, Security, and Observability each document their modules and full API.
